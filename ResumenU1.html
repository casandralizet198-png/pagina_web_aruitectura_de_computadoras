Modelos de Arquitecturas de Cómputo

La arquitectura de computadoras define cómo están organizados y cómo trabajan juntos el hardware y el software de una computadora. Establece la forma en que se procesan datos, se ejecutan instrucciones y se comunican los componentes.

🖥

Arquitectura Von Neumann

Modelo clásico donde la CPU utiliza una sola memoria para guardar tanto datos como instrucciones. Todo se comunica mediante un mismo bus.

💾

Arquitectura Harvard

Utiliza memorias separadas para datos e instrucciones, permitiendo acceder a ambos al mismo tiempo.

⚙

Arquitectura Segmentada (Pipeline)

Divide el procesamiento de instrucciones en varias etapas que se ejecutan en paralelo.

🔲

Multiprocesamiento

Consiste en usar varios procesadores para ejecutar programas y aumentar el rendimiento del sistema.

🧩

Clasificación de Flynn

Clasifica sistemas según cómo manejan instrucciones y datos:

  • SISO: una instrucción y un dato.
  • SIMO: una instrucción y múltiples datos.
  • MISO: múltiples instrucciones y un dato.
  • MIMO: múltiples instrucciones y múltiples datos.

Análisis de los Componentes

Los componentes de una computadora son las partes físicas que permiten su funcionamiento.

Componentes Internos

  • CPU
  • Motherboard
  • Fuente de poder
  • RAM
  • GPU
  • Tarjeta de sonido
  • Tarjeta de red

Componentes Externos

  • Monitor
  • Teclado y mouse
  • Impresora
  • Micrófono
  • Webcam

Arquitecturas RISC y CISC

R

RISC

Usa pocas instrucciones simples que se ejecutan rápidamente.

C

CISC

Utiliza instrucciones más complejas y variadas.

Unidad Central de Procesamiento (CPU)

La CPU es el “cerebro” de la computadora, encargado de ejecutar instrucciones y coordinar todas las operaciones del sistema.

🧮

ALU (Unidad Aritmética Lógica)

Realiza operaciones matemáticas y lógicas como sumas, restas y comparaciones.

⚡

Unidad de Control

Coordina y dirige la ejecución de instrucciones y el flujo de datos dentro del procesador.

🔌

Buses

Son vías de comunicación que conectan CPU, memoria y periféricos.

Memoria Principal

💾

RAM

Memoria temporal de alta velocidad que almacena los programas y datos que la CPU necesita usar inmediatamente.

📀

ROM

Memoria permanente que guarda el firmware y las instrucciones básicas para arrancar el sistema.

🚀

Memoria Caché

Memoria ultrarrápida entre la CPU y la RAM que almacena datos usados frecuentemente para acelerar el rendimiento.

Módulos de Entrada/Salida (E/S)

Permiten la comunicación entre la CPU y los dispositivos periféricos.

⌨

E/S Programada

La CPU controla directamente las transferencias de datos mediante software.

🔔

E/S por Interrupciones

La CPU continúa trabajando y el dispositivo avisa cuando termina mediante una interrupción.

Acceso Directo a Memoria (DMA)

📡

El DMA permite que dispositivos de entrada/salida transfieran datos directamente a la memoria sin usar constantemente la CPU.

Buses

Los buses son canales de comunicación que transportan datos entre componentes de la computadora.

  • Bus de sistema: conecta CPU y memoria.
  • Bus de datos: transporta información.
  • Bus de direcciones: indica ubicaciones de memoria.
  • Bus de control: coordina operaciones.
  • Buses locales: conectan dispositivos internos.
  • Buses periféricos: conectan dispositivos externos.

1.7 Interrupciones

Las interrupciones son señales que alteran temporalmente la ejecución normal de la CPU para atender eventos importantes.

🔄

Técnica de Poleo (Polling)

La CPU revisa constantemente el estado de un dispositivo para saber si necesita atención.

⚙

Sincronización con E/S

Permite que la CPU realice otras tareas mientras un dispositivo trabaja y luego responda mediante interrupciones.
